# Committee Management System

A comprehensive web-based platform for managing committee operations, finances, members, and communications.

## Features

### 📊 Core Features
- **Dashboard** - Real-time statistics and overview
- **Donations Management** - Track donations by date, amount, and type
- **Donor Database** - Manage donor information and history
- **Receipts** - Generate and track donation receipts
- **Expense Tracking** - Categorize and monitor expenses
- **Financial Reports** - Income, expenses, and balance summaries
- **Member Management** - Committee member profiles and roles
- **Events** - Schedule and manage committee events
- **Group Chat** - Real-time communication
- **Gallery** - Upload and manage photos
- **Announcements** - Share updates with members
- **Settings** - Customize committee information

### Adding Data

3. Fill in the required information

### Viewing Data
- Navigate to any section to view collected data
- Data is displayed in tables or cards
- Scroll to see more information

### Deleting Data
- Click the "Delete" button on any item
- Confirm the deletion

## Troubleshooting

### Data Not Saving?
- Check if local storage is enabled
- Clear browser cache
- Check browser console (F12) for errors

### Navigation Issues?
- Refresh the page
- Clear browser history
- Try a different browser
